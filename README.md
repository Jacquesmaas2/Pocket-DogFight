# Pocket Dogfight

Pocket Dogfight is a fast, funny 2D multiplayer space dogfighting game for mobile.

Two pilots. Tiny ships. Big explosions. Very questionable decisions.

## Technology
- Godot 4
- GDScript (typed where practical)
- 2D rendering
- Authoritative host/server multiplayer architecture
- Mobile-first controls
- VS Code as primary editor

## Core match
- 2-8 players
- Initial mode: Free For All
- Approx. 3-5 minute matches

## Priorities
1. Fun
2. Responsive controls
3. Great dogfighting
4. Multiplayer stability
5. Mobile usability
6. Visual polish

Never sacrifice responsive arcade gameplay for realism.
